To see how the next command works...first, set up a graph and phase.

phase boethus 3
phase boethus scale A minor
bars boethus fill Gm,4 Cm,4 Dm,4

Then, provide some timing if you want.

chord Gm in phase boethus arrange 3x -1 8th 0 8th 1 8th 2 8th


Now call the "next" subcommand on chord > graph.
chord graph next phase boethus
